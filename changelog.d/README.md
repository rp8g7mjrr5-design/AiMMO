# Changelog fragments

Workers add one file per PR here, named `<stream>-<short-slug>.md`, with 1 to 3 player-facing
bullet lines. The integrator folds them into `CHANGELOG.md` under the current week and deletes
them. This avoids every PR editing CHANGELOG.md and colliding.

Devlog notes and backlog notes work the same way, in `docs/devlog/<stream>.d/` and
`docs/workstreams/<stream>.d/`. See "Notes go in new files" in `docs/workstreams.md`.
